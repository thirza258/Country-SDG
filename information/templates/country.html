About these numbers

  • Goal scores run from 0 to 100 and measure distance to target: 0 is the worst outcome observed and 100 means the target has been reached on the indicators behind that goal. They are built to be compared across countries, not across goals.
  • The headline score is the published figure. It is the average of all 17 goals, with any goal a country is not assessed on filled in at its region's average for that goal — so for a country with a gap, the 17 numbers below will not average to it.
  • The headline score and rankings come from the {{ sources.report.label }}. The {{ profile.index_first_year }}–{{ profile.index_latest_year }} trends come from the {{ sources.index.label }}, so the two can differ slightly for the same goal.
  • Rankings cover the {{ profile.snapshot.of|default:"166" }} countries in the report. World, regional and income aggregates are excluded from every ranking.
    • {% if profile.not_assessed %}
  • Not assessed for {{ profile.name }}: {% for goal in profile.not_assessed %}Goal {{ goal.number }} ({{ goal.title }}{% if goal.not_applicable %}, {{ goal.not_applicable }}{% endif %}){% if not forloop.last %}; {% endif %}{% endfor %}. A gap is left blank rather than filled with a zero.
    • {% endif %}
  • Comparison markers on each card are unweighted averages of the countries assessed on that goal. The published regional and world aggregates are weighted differently and appear only on their own profile pages.
  • Quartile labels describe position within this dataset. They are not the Sustainable Development Report's own dashboard ratings, which are calculated per indicator.
